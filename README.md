# Ricin Toxin A-Chain Virtual Screening

Structure-based virtual screening of 1,993 approved drugs against the 
ricin toxin A-chain (RTA) active site using AutoDock Vina.

## Author
Ravi Sharma  
Department of Pharmaceutical Sciences  
Maharshi Dayanand University, Rohtak, Haryana-124001, India  
ORCID: 0009-0003-7239-9989

## Contents
- step1_inspect.py through step10_contacts.py — complete analysis pipeline
- screen_1BR5_exh8.csv — primary screen results (1,993 compounds)
- results_redock_summary.csv — re-docking results (50 compounds, 2 receptors)
- results_tier1.csv — Tier-1 hits after ligand efficiency filter
- library/library.csv — compound library with metadata
- protein/ — receptor PDB and box files
